# ノート分析・学習支援アプリ

中高生向け。板書ノートの写真をAIが分析し、重要ポイントの抽出と対策問題の生成・復習テストを行うWebアプリです。

## 機能

- **ホーム画面**: 科目選択、ノート写真のアップロード（最大4枚）、過去の学習セット一覧
- **分析結果画面**: AIが抽出した重要ポイントの確認・編集・追加・削除
- **テスト画面**: 一問一答・選択式・記述の10問を1問ずつ出題、正誤判定・解説、間違えた問題の再挑戦

## セットアップ手順

### 1. 必要なもの

- [Node.js](https://nodejs.org/) v18以上
- Anthropic APIキー（[Anthropic Console](https://console.anthropic.com/)で取得）

### 2. 依存パッケージのインストール

```bash
cd studyapp
npm install
```

### 3. 環境変数の設定

プロジェクトルート（`studyapp/`）に `.env.local` ファイルを作成し、以下を記述します。

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxxxxxxxx
```

`.env.local.example` をコピーして使用することもできます。

```bash
copy .env.local.example .env.local
# .env.local をテキストエディタで開き、APIキーを入力してください
```

### 4. 開発サーバーの起動

```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてください。

### 5. ビルド（本番用）

```bash
npm run build
npm run start
```

## スマートフォン実機での確認方法

PCと同じWi-Fiネットワークに接続されたスマートフォンから確認できます。

### 1. 開発サーバーをローカルネットワークに公開して起動

```bash
npm run dev -- -H 0.0.0.0
```

### 2. PCのIPアドレスを確認

**Windowsの場合:**

```
ipconfig
```

`IPv4 アドレス` の値（例: `192.168.1.10`）を確認します。

### 3. スマートフォンでアクセス

スマートフォンのブラウザで以下のURLを開きます。

```
http://<PCのIPアドレス>:3000
```

例: `http://192.168.1.10:3000`

## 注意事項

- APIキーは絶対にクライアント側のコードに含めないでください。サーバーサイド（`.env.local`）のみで使用します。
- 画像はAPIに送信されますが、アプリ内には保存されません。
- 学習セット（分析結果・問題）はブラウザのlocalStorageに保存されます。
- AIによる出題可能性の推定は実際の試験を予測するものではありません。
